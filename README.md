1. Название и описание задачи

Мини-графический редактор — учебная программа на Python, демонстрирующая основные принципы объектно-ориентированного программирования.

Программа позволяет работать с различными графическими фигурами: линиями, прямоугольниками, эллипсами и другими фигурами. Для каждой фигуры реализован собственный метод отрисовки.

Основная задача проекта — продемонстрировать применение инкапсуляции, наследования и полиморфизма в Python.

2. Архитектура проекта

В проекте используются три основных принципа ООП.

Инкапсуляция

Для каждой фигуры данные и методы, относящиеся к ней, объединены внутри соответствующего класса.

Базовый класс Figure содержит общие свойства фигур:

координаты;
ширину;
цвет.

Метод draw() используется для отрисовки фигуры.

Наследование

От базового класса Figure наследуются специализированные классы:

Figure
├── Line
├── Rect
├── Ellipse
└── Triangle

Каждый дочерний класс получает общие свойства и методы базового класса и может реализовать собственное поведение.

Полиморфизм

Все фигуры имеют общий метод draw(), но каждая фигура реализует его по-своему.

Благодаря этому разные объекты можно хранить в одном списке и обрабатывать единым циклом:

figures = [line, rect, ellipse, triangle]

for figure in figures:
    figure.draw()

Программа вызывает draw() у каждого объекта, несмотря на то, что объекты относятся к разным классам.

3. Пример использования

Пример создания фигур и их отрисовки:

line = Line((0, 0, 100, 100), 2, "black")
rect = Rect((10, 10, 100, 50), 3, "red")
ellipse = Ellipse((20, 20, 80, 60), 2, "blue")
triangle = Triangle((30, 30, 90, 90), 2, "green")

figures = [line, rect, ellipse, triangle]

for figure in figures:
    figure.draw()

После создания объектов они добавляются в общий список и обрабатываются одним циклом.

4. Результат работы

При запуске программы для каждой фигуры вызывается соответствующий метод draw().

Пример вывода в консоль:

Рисуется линия
Рисуется прямоугольник
Рисуется эллипс
Рисуется треугольник

Таким образом, для каждого объекта вызывается своя реализация метода draw().
